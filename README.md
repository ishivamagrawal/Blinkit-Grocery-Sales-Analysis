# BlinkIT Grocery Sales Analysis

A SQL-based exploratory analysis of BlinkIT grocery outlet sales data, covering revenue performance, product attributes, outlet characteristics, and pricing strategy.

## Dataset

`BlinkIT_Grocery_Data_UP.csv` — 8,523 item-level sales records with the following fields:

| Column | Description |
|---|---|
| Item_Fat_Content | Low Fat / Regular (raw data contains inconsistent labels: `LF`, `low fat`, `reg`) |
| Item_Type | Product category (Fruits and Vegetables, Snack Foods, etc.) |
| Item_MRP | Maximum retail price of the item |
| Outlet_Location_Type | Tier 1 / Tier 2 / Tier 3 city classification |
| Outlet_Size | Small / Medium / High |
| Outlet_Type | Grocery Store / Supermarket Type1 / Type2 / Type3 |
| Item_Visibility | Shelf visibility percentage |
| Rating | Customer rating |
| Item_Outlet_Sales | Revenue generated by the item at that outlet |
| Total_Sales | Supplementary sales figure |

## Approach

All analysis is done in `BLINKIT_QUERY.sql`, run against a PostgreSQL-style database:

1. **Data cleaning** — standardized inconsistent `Item_Fat_Content` labels (`LF`, `low fat` → `Low Fat`; `reg` → `Regular`).
2. **Core KPIs** — total revenue, average sales per item, average rating, total item count.
3. **Segmented analysis** — sales broken down by fat content, item type, outlet size, location tier, and outlet type.
4. **Price banding** — items grouped into Budget / Mid / Premium / Luxury MRP ranges to find the sweet spot for revenue.
5. **Combination analysis** — best-performing outlet type × location tier pairs, including a window function version for per-row comparison against group totals.

## Key Findings

**1. Total revenue: ₹1.86 crore (₹18,591,125.41)** across 8,523 items, at an average of ₹2,181 per item and an average customer rating of 3.97/5.

**2. Regular items slightly outsell Low Fat items on average.** Low Fat items generate more total revenue (₹1.19 crore vs ₹0.67 crore) simply because there are far more of them in the catalog (5,517 vs 3,006 items). But per item, Regular products actually average higher sales (₹2,215.74) than Low Fat (₹2,162.52) — so "healthier" labeling doesn't translate into stronger per-item performance.

**3. Medium-sized outlets are the most profitable.** Medium outlets lead on both total revenue (₹79.97 lakh) and average sales per item (₹2,202.46), ahead of Small outlets (₹68.07 lakh total, ₹2,168.52 avg) and High-size outlets (₹37.87 lakh total, ₹2,160.30 avg) — despite High outlets not having the fewest transactions.

**4. Tier 3 cities generate the most revenue overall, but Tier 1 has the strongest per-item performance.** Tier 3 leads in total sales (₹72.85 lakh) thanks to higher item volume (3,350 items), while Tier 1 has the highest average sale per item (₹2,187.51) despite the smallest item count (2,388) — suggesting Tier 1 outlets sell fewer items but at better realized value.

**5. The Premium price range (₹100–200 MRP) drives the most total revenue** (₹1.08 crore from 4,644 items), but the Luxury range (₹200+) delivers by far the highest average sale per item (₹3,678.82) despite far fewer items (1,440). Budget items (under ₹50) contribute the least to revenue (₹4.66 lakh) with the lowest per-item average (₹615.68). For maximizing total revenue, Premium is the sweet spot; for maximizing per-item value, Luxury pricing performs best.

## Additional Insights

- **Supermarket Type1** is the dominant outlet format, contributing ₹1.23 crore — nearly two-thirds of total revenue — and also has the largest item count (5,577).
- A window-function query identifies the best-performing outlet type + location tier combinations without collapsing row-level detail, useful for drill-down dashboards.

## How to Run

1. Load `BlinkIT_Grocery_Data_UP.csv` into a PostgreSQL (or compatible) database using the `CREATE TABLE blinkit(...)` statement at the top of `BLINKIT_QUERY.sql`.
2. Run the standardization `UPDATE` statements to clean `Item_Fat_Content`.
3. Execute the KPI and analysis queries (Q1–Q7) sequentially to reproduce the findings above.

## Files
